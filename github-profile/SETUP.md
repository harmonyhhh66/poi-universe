# Install this GitHub Profile README

GitHub **Profile README** does **not** come from `poi-universe/README.md`.

1. On GitHub create a **public** repository named exactly `harmonyhhh66` under your account `harmonyhhh66` (the repository name must match your **username**, not your display name). Initialize it with a README if convenient.
2. Copy the content of this folder's `README.md` into the new repository's **root** `README.md` (replace any placeholder content).
3. Commit the change to the default branch and visit `https://github.com/harmonyhhh66`.
4. To adjust personal details, edit that profile repository's README. To edit the website, edit the `poi-universe` repository.

No Personal Access Token or API key needs to be put in the README. If you already have a profile repository, update its README instead of creating another repository.
