# POI-006 — No Matter How Many Times

- **ID:** POI-006
- **Category:** ART & GAMES
- **Status:** IDEA
- **Kind:** 互动数字艺术 / Shoot 致敬作品
- **POI Inspiration:** Root 和 Shaw 的情感联系、S5E04《6,741》所代表的重复模拟与选择。作品画面与文案为原创。
- **One-line concept:** 两个光点在不断变化的环境中一次次靠近，某些连接始终留存。
- **Deliverable:** 无需登录的单页互动网页，可嵌入个人网站或作为独立 GitHub Pages 项目。
- **Why I want to build it:** 不直接放剧照、人物名字或对白，也让懂的人感受到 Shoot。
- **MVP:** 两个光点、可点击/移动交互、一段重置动画、一个由 `4A` / `6741` 暗示的隐藏结局。
- **Not in v1:** 不用 AI、不接服务器、不使用原剧音频/演员配音、不做复杂 3D。
- **Possible tech:** HTML + SVG/Canvas + CSS + JavaScript。
- **Privacy / safety / rights:** 无追踪、无个人数据收集；降低闪烁，支持 `prefers-reduced-motion`；剧集元素属于致敬而非官方素材。
- **Related:** POI-008（主题）、ROOT ACCESS（未编号）。

## How it works

1. 用户打开全黑页面，观察两个分离的光点。
2. 鼠标或触摸影响环境，无法完全控制它们。
3. 环境反复重置，但某个视觉关系保留。
4. 达到特定条件时出现短暂原创文字 `YOU FOUND ME.`，随后归于平静。

## Definition of done

- [ ] 桌面和手机都能体验完整互动
- [ ] 不依赖网络或账号
- [ ] 减少动态效果时仍能理解情节
- [ ] 有一份简短的作者注释解释原创与致敬边界
